# 美甲图片匹配器

基于 CLIP 深度特征的美甲图片相似度匹配系统。

## 功能

- **图片匹配**：上传图片，自动搜索相似款式
- **货品管理**：增删改查货品数据
- **导出表格**：导出为Excel或CSV格式
- 响应速度：< 1秒

## 命令行使用

```bash
# 建立特征索引（首次使用）
python matcher.py index

# 搜索相似图片
python matcher.py search -i /path/to/image.jpg -k 10
```

## 模型说明

- 模型名称：CLIP ViT-B-32
- 模型大小：约 1.1GB
- 用途：提取图片特征向量进行相似度匹配
- 下载来源：ModelScope（国内镜像，速度快）

## 技术说明

- 使用 CLIP ViT-B-32 模型提取 512 维特征向量
- 特征索引：1069张图片，15秒
- 单次搜索：< 1秒
- 兼容 macOS / Windows / Linux

## 注意事项

1. **首次使用必须下载模型**（约1.1GB）
2. 模型下载时间约2-5分钟（取决于网络速度）
3. 模型只需下载一次，之后可重复使用
